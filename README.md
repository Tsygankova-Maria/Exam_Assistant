# 🎓 Экзаменационный Таймер & Генератор Вопросов (Exam Assistant)

Небольшое локальное веб-приложение для проведения устных зачетов, опросов или подготовки к теоретическим экзаменам по алгоритмам. Приложение автоматизирует процесс выдачи вопросов и случайного выбора отвечающего студента по таймеру.

## 🚀 Основные возможности
* **Управление вопросами:** Ручное переключение теоретических вопросов из подготовленной базы кнопкой «Следующий вопрос».
* **Контроль времени:** Встроенный таймер обратного отсчета на **1,5 минуты (90 секунд)** с возможностью ручной остановки и запуска (кнопки Старт/Стоп).
* **Случайный выбор:** Автоматический выбор случайного ученика из списка каждые 90 секунд при обнулении таймера.
* **Локальный бэкенд:** Высокопроизводительный сервер на **C++**, отдающий данные через REST API.
* **Современный фронтенд:** Быстрое SPA-приложение на **React + Vite**.

## 🛠️ Системные требования
Для корректной сборки и работы приложения на вашем компьютере должны быть установлены:
* **Node.js:** строго версии **v22.17.0**
* **GCC Compiler:** версии **11.4.0** (Ubuntu 11.4.0-1ubuntu1~22.04.3)
* Утилита **make** (для сборки бэкенда)

## 💻 Установка и запуск

### 1. Клонирование и подготовка списков

```bash
git clone https://github.com/Tsygankova-Maria/Exam_Assistant.git
```

Если вы переносите проект, убедитесь, что файлы `backend/data/questions.json` и `backend/data/students.json` заполнены вашими актуальными данными в формате JSON-массивов.

---

### 2. Сборка и запуск бэкенда (C++)
Откройте первый терминал и перейдите в папку бэкенда:
```bash
cd backend
```

Скомпилируйте проект с помощью Makefile:
```bash
make
```
*После успешной компиляции в папке появится исполняемый файл `exam_server`.*

Запустите сервер:
```bash
./exam_server
```
*По умолчанию бэкенд начнет слушать запросы на локальном порту (например, `http://localhost:8080`). Не закрывайте этот терминал.*

---

### 3. Настройка и запуск фронтенда (React)
Откройте второй терминал и перейдите в папку фронтенда:
```bash
cd frontend
```

Установите все необходимые Node-зависимости:
```bash
npm install
```

Запустите локальный сервер разработки Vite:
```bash
npm run dev
```

В терминале отобразится локальная ссылка (обычно `http://localhost:5173`). Откройте её в любом браузере.

## ⚙️ Настройка своей базы вопросов и студентов

Приложение работает на основе статических списков, которые хранятся в формате JSON в папке `backend/data/`. Вы можете легко заменить демонстрационные данные своими собственными.

### 1. База вопросов (`backend/data/questions.json`)
Файл представляет собой JSON-массив объектов. Каждый вопрос **обязательно** должен иметь уникальный числовой идентификатор `id`, категорию `topic` и текст самого вопроса `text`.

**Пример заполнения:**
```json
[
  {
    "id": 1,
    "topic": "Complexity",
    "text": "Приведите пример алгоритма, работающего за O(n^3 * log n)."
  },
  {
    "id": 2,
    "topic": "Sorting",
    "text": "Какова асимптотика работы алгоритма сортировки слиянием? Является ли она устойчивой?"
  },
  {
    "id": 3,
    "topic": "Data Structures",
    "text": "За сколько работают основные операции в стеке?"
  }
]
```

### 2. Список студентов (`backend/data/students.json`)
Файл представляет собой простой JSON-массив, состоящий из строк с именами и фамилиями учеников.

**Пример заполнения:**
```json
[
  "Иванов Иван",
  "Петров Петр",
  "Сидорова Анна",
  "Кузнецов Алексей",
  "Смирнова Мария"
]
```

⚠️ **Важные правила при изменении файлов:**
* **Синтаксис JSON:** Следите за тем, чтобы после последнего элемента в массиве или объекте **не стояла запятая** (это частая ошибка, из-за которой C++ парсер JSON может выдать ошибку при старте).
* **Кодировка:** Сохраняйте файлы исключительно в кодировке **UTF-8**, чтобы кириллические символы в вопросах и именах корректно отображались в браузере.
* **Перезапуск сервера:** Если вы изменили файлы `questions.json` или `students.json` во время работы приложения, обязательно перезапустите C++ сервер (`./exam_server`) в терминале, чтобы он перечитал новые данные из папки `data`.

## ⚙️ Использование приложения
1. Откройте приложение в браузере. Вы увидите первый вопрос из базы данных.
2. Нажмите кнопку **«Старт»**, чтобы запустить таймер на 1,5 минуты.
3. По истечении 90 секунд приложение автоматически выберет случайного студента и обновит имя на экране, перезапустив таймер.
4. Вы можете нажать **«Стоп»** в любой момент, чтобы приостановить отсчет времени (например, для дополнительных вопросов).
5. Кнопка **«Следующий вопрос»** позволяет вручную обновить текущее задание для аудитории.
